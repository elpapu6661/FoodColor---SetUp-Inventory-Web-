### Funcionalidades Migradas

**Catálogo Público (puerto 8080/):**
- GET `/` → index.html (Thymeleaf)
- GET `/api/public/productos?category=&q=` → JSON con filtros
- POST `/api/public/contact` → Formulario contacto

**Panel Inventario (puerto 8080/inventory - requiere login):**
- GET `/login` → Formulario login (admin/foodcolor2026)
- GET `/inventory` → Panel SPA 3 tabs (Registrar, Ver Stock, Crear Pedido)
- GET `/api/inventory/productos` → Lista productos
- POST `/api/inventory/productos` → Crear/actualizar producto (merge por nombre)
- GET `/api/inventory/pedidos` → Historial boletas
- POST `/api/inventory/pedidos` → Crear pedido + validar stock + generar boleta

### Seguridad
- Spring Security con form login
- Usuario en memoria: admin / foodcolor2026 (BCrypt)
- Rutas públicas: `/`, `/api/public/**`, `/login`, `/logout`, assets
- Rutas protegidas: `/inventory`, `/api/inventory/**`

### Datos
- Almacenamiento en JSON files (`data/products.json`, `data/pedidos.json`)
- Thread-safe con ReentrantReadWriteLock
- Inicialización automática si no existen archivos

## Para Compilar y Ejecutar

```bash
# Opción 1: Usar Maven wrapper (si se genera)
./mvnw spring-boot:run

# Opción 2: Maven instalado + JDK 21+
export JAVA_HOME=/path/to/jdk-21
mvn spring-boot:run

# Opción 3: Compilar JAR y ejecutar
mvn clean package -DskipTests
java -jar target/foodcolor-inventory-1.0.0.jar
```

**Nota:** El JDK actual es 25 (no soporta `--release 21`). Se requiere JDK 21 LTS.
